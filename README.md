# osnova-docs

Документация Osnova: продукт, архитектура, ADR и правила участия.

## Статус

Стартовая основа документации.

## Лицензия

Документация в этом репозитории распространяется по лицензии Creative Commons Attribution 4.0 International.

## Команды

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

## Связанные репозитории

- `osnova-spec` описывает открытый folder-based формат проекта.
- `osnova-core` реализует общие TypeScript-примитивы проекта.
- `osnova-desktop` содержит Windows-first Electron-клиент.
- `osnova-plugin-sdk` задает поверхность разработки плагинов.
- `osnova-ai-runtime` отвечает за опциональный локальный AI runtime.
- `osnova-plugins` содержит каталог плагинов.

## Правила участия

Документация должна быть точной, краткой и привязанной к реализации. Для решений, которые затрагивают несколько репозиториев, используется формат ADR.
