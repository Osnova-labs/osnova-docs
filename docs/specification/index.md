# Спецификация

Авторитетное описание формата проекта находится в `osnova-spec`.

Этот раздел кратко фиксирует контракт:

- Проект является папкой.
- `osnova.json` является manifest.
- `notes/` содержит Markdown-конспекты.
- `assets/` содержит пользовательские файлы.
- `.osnova/` содержит application metadata, кеши и индексы.

Расширенные папки вроде `cards/`, `graph/` и `ai/` являются опциональными и не должны требоваться для минимального проекта.
