# Система плагинов

Плагины расширяют Osnova через явные manifests и регистрацию команд.

## Границы

- Каждый плагин объявляет identity, version, entry point и permissions.
- Команды регистрируются со стабильными ID.
- Host APIs передаются через контролируемый plugin context.
- Доступ к файлам должен быть ограничен активным проектом и заявленными permissions.

Desktop-клиент отвечает за discovery плагинов, проверку permissions, загрузку и выполнение команд. SDK отвечает за TypeScript-контракт для авторов плагинов.
