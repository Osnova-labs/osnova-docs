# Карта репозиториев

## osnova-docs

Документация по продукту, архитектуре, ADR и участию.

## osnova-spec

Открытая спецификация folder-based формата проекта, включая JSON Schema и примеры.

## osnova-core

Общие TypeScript-пакеты для доменных типов, операций с папкой проекта, manifest и validation.

## osnova-desktop

Windows-first Electron-приложение с React renderer и TypeScript-сервисами.

## osnova-plugin-sdk

SDK для авторов плагинов. Определяет plugin manifests, permissions и черновик command API.

## osnova-ai-runtime

Опциональный локальный runtime для AI-функций. Лицензируется отдельно от desktop-клиента.

## osnova-plugins

Каталог и примеры плагинов.
