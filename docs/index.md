# Osnova

Osnova - local-first модульная среда для учебных и исследовательских проектов.
Проект представляет собой обычную папку с материалами, сессиями, артефактами и
подключаемыми инструментами.

Windows и macOS являются равноправными desktop-целями. Первый стабильный
контракт - folder-based формат проекта.

## Направления продукта

- [Osnova Reborn](./product/osnova-reborn.md): принятое целевое направление.
- [Видение](./product/vision.md): краткое продуктовое обещание.

## Репозитории

- `osnova-docs`: продуктовая, архитектурная и ADR-документация.
- `osnova-spec`: открытый формат проекта и JSON Schema.
- `osnova-core`: общие TypeScript-библиотеки для project IO и валидации.
- `osnova-desktop`: desktop-клиент на Electron, React и TypeScript.
- `osnova-plugin-sdk`: TypeScript SDK для плагинов.
- `osnova-runtime` (`osnova-ai-runtime` до переименования remote): общий локальный control plane с опциональным AI.
- `osnova-plugins`: каталог плагинов.
