# Osnova

Osnova - local-first рабочая среда для учебных проектов. Проект представляет собой обычную папку с Markdown-конспектами, файлами, метаданными и необязательными структурированными учебными объектами.

Первый продуктовый интерфейс - Windows desktop-клиент. Первый стабильный контракт - folder-based формат проекта.

## Направления продукта

- [Текущее видение](./product/vision.md): local-first рабочая среда для учебных проектов.
- [Osnova Reborn](./product/osnova-reborn.md): исследуемая модульная среда учебных и исследовательских проектов, объединяющая файлы, знания, инструменты, артефакты и опциональную агентную оркестрацию.

## Репозитории

- `osnova-docs`: продуктовая, архитектурная и ADR-документация.
- `osnova-spec`: открытый формат проекта и JSON Schema.
- `osnova-core`: общие TypeScript-библиотеки для project IO и валидации.
- `osnova-desktop`: desktop-клиент на Electron, React и TypeScript.
- `osnova-plugin-sdk`: TypeScript SDK для плагинов.
- `osnova-ai-runtime`: опциональный локальный AI runtime.
- `osnova-plugins`: каталог плагинов.
