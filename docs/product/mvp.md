# MVP

Первый полезный релиз Osnova должен поддерживать:

- Создание папки проекта с `osnova.json`, `notes/`, `assets/` и `.osnova/`.
- Открытие существующей папки проекта.
- Чтение и валидацию `osnova.json`.
- Создание Markdown-конспектов в `notes/`.
- Отображение метаданных проекта и последних конспектов.
- Хранение всех данных проекта в выбранной папке.

MVP не требует cloud sync, packaged plugins, редактирования графа, AI-функций или архивного транспорта `.osnp`.
