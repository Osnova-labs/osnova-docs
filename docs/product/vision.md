# Видение продукта

Osnova помогает студентам создавать и хранить учебные проекты как долговечные локальные папки. Папка остается полезной без приложения, может копироваться обычными средствами и позднее передаваться как архив.

Продукт сосредоточен на личной учебной работе:

- Markdown-конспекты для понятий, лекций и кратких материалов.
- Локальные файлы, которые хранятся рядом с проектом.
- Структурированные карточки и связи, когда обычных заметок недостаточно.
- Опциональная локальная AI-помощь, которая не определяет основной формат.

Система должна сохранять простой путь очевидным, а расширенные возможности - добавочными.
